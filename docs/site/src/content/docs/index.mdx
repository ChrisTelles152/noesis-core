## Why Noesis exists

Most adaptive-learning platforms hide their adaptation logic behind a
black box. Noesis is the opposite — every recommendation is the output
of a function you can step through, and every event the engine processes
can be replayed to reproduce the same state byte-for-byte.

<CardGrid stagger>
  <Card title="Deterministic core" icon="approve-check">
    BKT, FSRS, session planner — all pure, all replayable. Inject your own clock and id generator at
    construction time; the engine *requires* them so a silent `Date.now()` can't sneak in.
  </Card>
  <Card title="NALS cognitive vector" icon="puzzle">

  </Card>
